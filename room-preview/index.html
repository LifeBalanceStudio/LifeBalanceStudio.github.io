화면이 느릴 때

아래 주소를 복사해 브라우저 주소창에 붙여 넣으세요. 설정을 변경한 뒤에는 브라우저를 다시 시작해 주세요.

  1. 설정의 시스템 항목에서 가능한 경우 그래픽 가속 사용을 켭니다.
  2. Windows에서는 ANGLE 그래픽 백엔드도 확인합니다. 기본값(Default)으로 설정하고 다시 시작합니다. D3D11 WARP는 소프트웨어 렌더링 옵션입니다.
  3. 그래픽 정보의 GL_RENDERER에서 실제 그래픽 장치를 확인합니다. Microsoft Basic Render Driver나 SwiftShader가 표시되면 소프트웨어 렌더링 중일 수 있습니다.
크롬 공식 성능 도움말
  1. 설정에서 성능 항목을 찾습니다. 버전에 따라 일반 또는 탭·탐색 항목에 있습니다.
  2. 권장 성능 설정 사용을 해제해 세부 항목을 표시한 뒤, 가능하면 하드웨어 가속 사용을 켜고 다시 시작합니다. 항목이 보이지 않으면 아래 공식 도움말에서 그래픽 드라이버 지원 여부를 확인합니다.
  3. 문제 해결 정보의 그래픽 항목에서 사용 장치와 WebGL 상태를 확인합니다.
파이어폭스 공식 성능 도움말 · 그래픽 드라이버 도움말

모바일에는 위의 PC용 그래픽 설정이 없을 수 있습니다. 브라우저를 최신 버전으로 업데이트하고, 아래의 절전 표현이나 기존 홈페이지를 이용해 보세요.

PC용 크롬·파이어폭스의 안내가 필요하면 위에서 브라우저를 선택할 수 있습니다.
